贴这四个东西，一次就说清

  1. --doctor 的完整输出（十七行，别删减，WARN 也有信息）

  3. 客户端：Claude Code、Cursor、Cline 还是别的

有些东西不用发：API key（打码或者删掉）、你的配置里的私密地址、任何客户数据。诊断用不着这些。

三种最常见的，你可能自己就能解决

401 / 鉴权失败。九成是 key 没进客户端进程——系统环境变量和程序自己的环境变量是两回事。用 curl 直连打一次，通了就是客户端的问题。

Model not available / 404。模型名对不上。教程里的名字经常过期，直接问服务端要：curl $BASE/models，把返回的 id 原样填回去。

一直转圈然后超时。HTTP/2 协商失败也会这样，报错里一点线索没有。把客户端的 HTTP 兼容模式切到 1.1 试一次，这一步不改任何配置，试错成本是零。
